Metrics

Metrics

Metrics by Maximal Intelligence (miMetrics) tracks how often files and web pages are cited in AI responses across all sessions, and whether those come from internal or external sources, giving your organization the ability to determine what data it needs next to maximally leverage AI and improve its competitiveness.

Workflows that depend on internal data and expertise provide a competitive advantage. Discover those workflows with Metrics.

Quickstart

1. Sign up for Metrics

Go to metrics.maximalintelligence.com (opens in a new tab) and sign up with email and password or Gmail.

2. Add the plugin

Add to Claude (opens in a new tab)
  1. Click the Add to Claude button.
  2. Click Next, then click Add.
  3. Click Connect and sign in to miMetrics.
  4. Add instructions that tell Claude to call miMetrics MIMaximalyour account (Maximal) → Settings → Your Claude → Instructions.
Note
To ensure the plugin is always running follow the procedures in the troubleshooting section.
Add for your organization (opens in a new tab)
  1. Click Add for your organization. It opens the same dialog on the admin path (Organization settings → Connectors).
  2. Set Log-Citations to Always allow there.
  3. Paste the instructions into Organization settings → Organization and access → Organization instructions.
Note
To ensure the plugin is always running follow the procedures in the troubleshooting section.
Add to ChatGPT (opens in a new tab)
  1. Click the Add to ChatGPT button.
  2. Click Add → Add custom MCP Server.
  3. Enter name Maximal Intelligence Metrics and the MCP URL https://metrics.maximalintelligence.com/mcp.
  4. Click Create as plugin.
  5. Click Continue to Maximal Intelligence Metrics and sign in to miMetrics.
  6. Add instructions that tell ChatGPT to call miMetrics MIyour account → Settings → Personalization → Custom instructions → edit.
Note
To ensure the plugin is always running follow the procedures in the troubleshooting section.

Using Metrics

Go and chat with your AI and ask it to cite sources. Then head back to metrics.maximalintelligence.com (opens in a new tab) and check out the updated dashboard!

What gets logged

miMetrics instructs the AI to only log locations of information. Actual information is not logged by miMetrics but available through enterprise contracts. Locations of information include:

  1. Filepaths of documents or files available through other connectors or through your AI's search
  2. Web page URLs and API endpoints with data available through web search tools
  3. Filepaths of files and other context added directly to a project

Projects

Organize your work into different projects on Maximal Intelligence for specific workflows. This lets you track which workflows are using internal data or external data.

To edit projects, use the dashboard and select the settings. There, you can:

  1. Rename the project
  2. Invite or remove other members
  3. Delete all data

Using Claude

Organize your work into projects on Claude as well: upload context to that project and see if Claude uses it for your workflows. This is the best practice to keep other data separate and secure. This also helps Claude focus on your specific internal data.

Troubleshooting

If your dashboard isn't updating

1. Set the correct permissions

If you are asked for permissions before citing each time, open Customize → Connectors → Maximal Intelligence Metrics → Tool permissions and set Log-Citations to Always allow.

2. Update the instructions

Paste the instructions into Organization settings → Organization and access → Organization instructions.

Data security

Because the assistant reports its own citations, it could pass information that isn't a file path, or include an API token in a web address. Metrics encrypts all traffic and also takes extensive steps to make sure that insecure information is not stored, reporting back to you directly in the AI chat if issues were found. Using Metrics requires accepting the Maximal Intelligence Terms of Service; see also the Privacy Policy.

  • Organizations are invite-only.
  • Two-factor sign-in (TOTP).
  • OAuth with consent for each app, which you can revoke.
  • Organization members can delete all of its citations, and you can delete your account.

If you require more stringent data security guarantees, we welcome setting up enterprise solutions for you instead.
